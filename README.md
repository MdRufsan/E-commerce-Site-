# E-commerce-Site
This is our E-Commerce project SE331
This project is a dynamic and responsive E-commerce website built using PHP with MySQL for database management. The platform allows users to browse products, search items, register/login, add products to the cart, and place orders through a simple interface. Admins can manage product listings and view customer orders. HTML and CSS were used for frontend design. The system demonstrates how PHP can be used to build a functional online shopping platform suitable for small to medium-sized businesses.
